# TG-DND

> Рабочее название: DnD Party Finder.

Telegram-бот и Mini App для набора партий в настольные ролевые игры. До начала игры
игроки общаются анонимно, чтобы смелее вживаться в роли.

## Как это выглядит для игрока

1. Игрок запускает основного бота. Бот присылает напоминания о грядущих играх
   и открывает Mini App.
2. В Mini App игрок видит список кампаний: описание, дату, стоимость,
   сколько мест всего и сколько занято.
3. Записавшись на кампанию, игрок получает в личном чате с ботом отдельный
   **топик** этой кампании.
4. Всё, что игрок пишет в топик, бот копирует остальным участникам кампании
   от своего имени, с подписью-псевдонимом. Ответы, форматирование, фото,
   видео, голосовые и альбомы сохраняются.
5. Игрок может снять анонимность в любой момент. Для остальных анонимность
   снимается автоматически после первой встречи.
